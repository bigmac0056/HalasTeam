## 📋 Быстрая проверка

### 1. Клиент настроен?
```bash
# Проверьте наличие файла
cat client/.env

# Должно быть:
# VITE_API_BASE_URL=https://halasteam.onrender.com
```

### 2. Запуск проекта

**Терминал 1 - Клиент:**
```bash
cd client
npm run dev
```

**Терминал 2 - Локальный сервер (опционально, для разработки):**
```bash
cd server
npm run dev
```

### 3. Проверка в браузере

1. Откройте http://localhost:5173
2. Откройте DevTools (F12) → Console
3. Проверьте, нет ли ошибок CORS
4. Попробуйте зарегистрироваться/войти

---

## 🔧 Если что-то не работает

### CORS ошибка?
→ Настройте `ALLOWED_ORIGINS` на Render.com

### Запросы идут на localhost?
→ Проверьте `client/.env` файл и перезапустите dev сервер

### 401 Unauthorized?
→ Проверьте, что токен сохраняется в localStorage
